# 天意人力资源系统 · ty-hr

专门服务餐饮集团、多品牌、多门店的人力资源系统。以员工工资和企业人力成本为结果，以人事组织为底座，优先建设薪酬、高级排班考勤及绩效。

## 本地启动与检查

需要Node.js 22或以上。当前原应用命令：

```sh
cd code
npm ci
npm run test:new
npm run serve
```

`DATABASE_URL`连接真实PostgreSQL；未配置时原应用使用PGlite，内存模式重启会清空，持久模式须显式配置目录。生产部署将要求显式数据连接，不能依赖默认演示数据。

当前工作台`/workspace`；存活及就绪探针`/livez`、`/readyz`。账号初始化按[演示角色](docs/runtime/demo-roles.md)显式确认虚构环境，初始口令由本地安全配置提供，不在仓库公布。

## 云端复制边界

目标是React + Node单进程 + PostgreSQL兼容REST/Broker。平台必须支持所需事务或领域级原子RPC；不能把多条SQL拆成无状态HTTP调用。千问云端具体数据库能力及Broker契约需要配置和适配验证，不能仅凭静态页面能打开宣称全系统迁移成功。

历史迁移和有用业务代码保留用于可验证复用；旧截图、重复过程文档及无用提取工具已从工作树移除。历史仍可在Git中追溯，当前文档以本目录为准。
