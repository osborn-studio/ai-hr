# 2026年10月排班考勤与工资演示

本演示从独立虚构记录构建排班、打卡、考勤、绩效和工资完整链条。用户提供的客户原件只用于理解结构，没有导入真实姓名、工号、工资或门店数据。系统没有付款操作。

## 核算与范围

每个班段保存计划起止、实际工作公司、部门与档口；人日另存原雇主和雇佣。原始打卡不覆盖，缺卡另存补卡理由、核定人及时间。同一个永久人员在不同门店的班段统一检查重叠，支持跨午夜，固定按当地+08:00显示。

日报与月报从同一班段视图汇总。实际打卡时长、落在计划内的核定在岗时长、请假时长、独立加班时长分别列示。月报与工资采用分钟来源，显示时转换小时，不逐段先四舍五入再求和。

接收门店只看到本店借调班段，原雇主的工资仍按雇佣公司地区核算；跨品牌支援不自动变更合同或税务地区。跨品牌远程支援是合成业务案例，不代表跨境工作许可或实际到场安排。员工“我的考勤”从会话绑定本人；外部人员参数不能替换身份。

有未处理缺卡、待批换班借调或倒置的实际上下班时间时不能封存。封存后保留原始记录，不能直接改写或删除。当前10月样本均已处理并封存；原排班采集、规则、假期、审批和封账操作入口保留在“兼容排班工具”及假期菜单。

## 工资和绩效

10月新工资从封存考勤提取核定在岗、事假缺勤、病假、加班、带薪假与节日在岗工时；所选10月绩效从确认结果独立过账，不接受手填冒充。两套算法可以在测试帐套自行选择，无需外部客户审批。已确认工资保留快照和来源链接，未执行付款。

内地演示含基本工资、餐费津贴、加班、假勤扣款、个人及单位社保公积金与合成累计个税参数。香港演示含月薪或时薪、假期计薪、加班、津贴和显式资格的MPF，不使用内地社保个税。货币分别汇总。

工资除数、基数、比例、加班倍率、病假80%示例、小时工资、税额累计等都是演示配置，不是已确认客户制度或通用于所有地区的法定默认。香港完整假期资格、12个月平均日薪及供款豁免还可在原有香港核验工具中单独维护；本演示工资不声称自动完成所有真实法定资格审查。

香港样本采用周日休息、10月1日假日、10月18日与休息日重叠后19日补假示例。国庆标签在内地轮休表中与实际是否上班分开记录，额外节日工资参数明确列示。
