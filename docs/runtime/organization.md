# 集团品牌公司门店与编制

天意HR将经营组织明确为集团、品牌公司、门店三个层次。每层均可设置内部部门、岗位和编制，餐饮档口归口到部门，员工通过带有效期的雇佣及任职关联组织。门店作为独立核算的经营公司，法定雇佣主体另行记录。

演示组织是天意集团、香香鱼米品牌公司及10家内地门店、大富烤肉品牌公司及10家香港门店，共23个经营组织节点。集团总帐包含两个品牌子帐；集团汇总不把人民币和港元相加。

集团定义标准岗位和职级，各级公司岗位可承接直属上级的同一标准岗位，数据库校验集团、上级组织和标准岗位一致。集团及品牌公司均设人力资源部；HR总监、主管、招聘、薪酬、培训、人事等岗位进入目录。公司岗位、部门、档口、系统权限角色分别管理。

组织架构图使用新版组织基础，不再把旧演示部门当作集团树。点击集团、品牌、门店或部门，可以查看任职有效日的成员、岗位体系、编制预算；点击人员可查看当前账号授权范围内的入离职、复聘和多门店经历。永久人员编号不随调动改变。

虚构人员TY000001保留历史内地离职、香港入职及香港职级变化，另自2026年11月16日起在内地门店有一段并行兼职雇佣。该任职不会倒灌到10月考勤，也不会改写已确认的历史工资。

## 总监范围

| 角色 | 演示登录名 | 范围 |
|---|---|---|
| 集团HR总监 | group_hr_director | 天意集团全部HR能力及集团内完整跨品牌历史；其他集团隔离 |
| 香香鱼米公司HR总监 | company_hr_director | 本品牌公司及下属10店 |
| 大富烤肉公司HR总监 | hk_hr_director | 本品牌公司及下属10店 |
| 单店公司HR总监 | store_hr_director | 香香鱼米01店 |

公司总监可操作授权公司的业务，不维护集团标准、集团统一班次或跨品牌授权。集团HR总监可维护本集团标准和授权；不能新建无授权集团。admin仍为系统配置，demo仍为全部权限，boss仍为只读。

## 编制口径

编制按月份核定，分公司总预算、部门预算、岗位预算。下级公司与直属部门共同占用上级公司的预算，下级部门与本部门岗位共同占用部门预算。保存时数据库锁定同集团同月的分配，阻止超额下分和将父级额度降低到已分配合计以下。

编制页面支持新增和调整预算、按观察日期显示占用、空编、超编及调整依据。组织汇总按不同人员去重；公司和岗位按有效主任职计入；跨公司并行雇佣分别占用相应公司，但集团人数去重。

当前演示为2026年11月预算。编制用于计划与人数比较，尚未将超编配置成阻止所有招聘或入职动作的硬性门禁。原编制审批工具保留在兼容业务中，不能把两套预算当作同一本已审批账。

## 初始化与验证

已有虚构帐套、人员账号初始化后，可显式运行：

```bash
node tools/init-organization-demo.mjs --confirm-synthetic
```

需要明确持久化数据库和本地运行目录。该工具幂等，不接管已有同名账号、不重置旧密码、不覆盖客户资料；先备份数据库并按可信迁移账本应用207、208。账号明文仅留本地权限受限文件，不提交仓库。

三层组织、总监范围、跨品牌履历、编制拒绝超额及接口行为在`test/advanced-time.test.mjs`中验证。
