# 外包供应商人员与账单协作

本模块连接企业HR、外包人事供应商和服务人员。供应商、合同、服务关系、账单、沟通待办独立保存，并关联既有组织、永久人员身份及已确认工资来源。界面沿用蓝白金、二级菜单和分页，所有演示资料均独立虚构。

## 对象与边界

- 直营雇佣：门店公司保留原雇佣关系。
- 人员服务外包：明确供应商、实际雇主、服务公司、服务岗位和期限，不把外包标签当作劳动合同或资格认定。
- 劳务派遣：单独的合同类型，与人员外包、薪酬代发分别建档。当前没有派遣资格自动认定或派遣计税演示。
- 薪酬代发：供应商办理受托人事和资金服务，原劳动关系保持在直营公司。不能把代发服务误作雇主变更。

供应商和公司均按集团隔离。供应商档案维护名称、编码、地区币种、联系人、资质状态及期限、账单抬头、银行名称和账号尾号、内部管理备注。停止合作通过停用保留历史，不删除已发生服务。

合同明确服务类型、公司范围、生效及到期、收费方式、单价或服务费、条款和可共享薪酬明细。已发生人员或账单的合同不覆盖原版本，另建合同维护新条款。人员服务关系关联明确的用工或服务记录，保存原实际雇主及派驻门店。

## 三种门户

| 身份 | 可办理内容 | 范围 |
|---|---|---|
| 企业HR | 供应商维护、服务合同、服务关系、沟通与待办、账单草稿和双向确认 | 本岗位授权的集团或公司 |
| 供应商联系人 | 自己合同内的服务人员、已共享账单、差异与回复 | 绑定的一家供应商，不开放其他供应商或HR内部备注 |
| 外包服务人员 | 本人服务、本人排班考勤、培训和参与方共享沟通 | 本人身份从会话绑定，不开放直营工资、内部假期额度、供应商账单 |

老板为只读；集团HR总监、公司HR总监继续按既有集团或公司范围授权。外包人事专员仅办理外包门户业务，不因此获得直营工资或系统配置权限。普通直营员工只有被纳入代发服务时才显示本人的外包服务入口。

组织编制同时显示直营与外包在岗人数。旧版内地算薪入口在目标期间涉及外包服务或并行雇佣时拒绝执行，避免按旧的单雇佣模型计薪；历史直营月份仍可核算。集团及公司HR总监维护各自业务范围，平台全局配置由系统管理员办理。公司HR可维护本公司人员及自己新建的待入职档案，不能改动其他品牌人员。

## 沟通与待办

事项可关联合同、人员、账单、类型、主题和处理期限。当前支持考勤核对、服务到岗、离场、薪酬资料、账单差异等类型。状态区分待HR、待供应商、待员工和已解决。

消息分参与方共享、HR与供应商、仅HR内部三种可见范围。个人只能进入与本人关联的事项；供应商只能进入绑定合同；HR内部消息不会通过供应商或个人的接口返回。解决后保留只读回复链。

当前消息仅保存在系统内部。没有连接邮件、短信、钉钉或实际向任何外部联系人发送内容。

## 对账与资金

历史人事外包样表包含83列，覆盖基本及合同工资、津贴、假勤、个人及企业社保公积金、商业保险、税额累计、不同支付渠道、服务费和企业承担成本。它是历史结果表，本次只参考字段结构，没有复制其真实人员、金额或猜测缺失公式；旧年份比例不作为当前默认规则。

账单按合同、月份、版本保存。净薪代发资金、个人供款、企业供款、代扣税款、保险、服务费、税费、其他费用和调整项分别列示，不将工资总额与净薪及代缴资金重复相加。不同币种和不同版本不直接合计。

薪酬代发草稿可从对应人员的当月已确认工资生成分项，并从明确的合同读取按人或固定服务费。工资来源绑定工资行和分项，数据库再次比对金额，拒绝篡改、移除来源或同一账单重复添加。同一工资资金分项不能通过另一份合同再次确认结算。

服务工时类合同可从本合同有效服务期间的封存考勤提取本雇佣、本人、本服务公司的核定分钟，按合同单价计算。缺少封存服务工时则阻断，不用10月直营工时冒充11月外包服务。人工验收或其他费用可以有据单列，由双方核对，不宣称自动验证外部凭证真实性。

账单草稿可维护费用；共享时冻结明细快照。供应商和HR须针对同一明细版本分别确认，双方完成后锁定。差异转为争议，复制到下一版本调整，旧版本保留。新版本不等于另一笔付款；当前有效账单应按同合同同月最新确认版本查看，不能汇总所有历史版本。

可导出CSV并打开服务端打印版，打印内容为对账单，不是发票，也不代表付款。税费和发票规则按合同明确配置，本模块不从旧表自动套用现行税率。

## 初始化与验证

```bash
node tools/init-outsourcing-demo.mjs --confirm-synthetic
```

需要明确持久化数据库、可信迁移账本、既有虚构组织账号和完整10月演示数据。先备份，再显式应用209、210迁移。工具不会导入客户文件，不重置已有口令；新增账号仅在本地保存初始凭据。重跑保留中文姓名、历史数据与已分配账号。

回归脚本为`test/outsourcing.test.mjs`，覆盖供应商维护、人员类型、历史工资不改写、供应商隔离、内部消息、本人自助、账单冻结、更正版本、资金来源和跨合同防重复。界面检查覆盖档案保存及恢复、三种门户、账单、中文姓名、回复和权限说明。
