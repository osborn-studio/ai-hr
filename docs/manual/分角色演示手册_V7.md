# 天意人力资源系统分角色演示手册

本手册用于V7现场演示，按角色提供可重复查看的路线。演示前确认使用天意集团专用演示环境，先备份，优先查看已有状态。提交审批、核定、交卷或支付结果会改变演示记录，需按讲解目标在独立复本中操作。全部账号及口令见本地账号手册，本手册只列登录名。

## 演示准备

确认系统已启动，登录名和口令来自本地账号手册。PC建议1440像素以上，手机建议393像素左右。历史工资与考勤选2026年10月，外包服务选择2026年11月并明确截至17日。

## 1 集团HR组织与人员全貌

角色：集团HR总监。登录名：group_hr_director。建议时长：5分钟。

说明集团、品牌公司与门店的关系，以及同一人员在不同公司任职时如何保持同一永久编号。

操作路线：人事组织架构 / 人事花名册 / 员工全貌 / 入转调离。

1. 打开人事组织架构，展示天意集团、香香鱼米及大富烤肉。展开集团与品牌部门，再展开内地及香港门店。
2. 切换树状图和网状图，点击一个部门或岗位，查看成员。进入编制与空缺，分别找到剩余名额、满编及超编记录。
3. 打开花名册，搜索周嘉禾或永久编号TY000001，进入员工全貌，按时间查看内地、香港和门店任职经历。
4. 打开另一名已调动人员，比较当前部门岗位与10月历史记录，再进入入转调离查看办理状态与实际生效日。

讲解要点：重点展示永久人员、实际雇佣和岗位任职的区别。集团HR可在集团内查看跨品牌经历，姓名和当前门店不是历史统计的唯一键。

## 2 品牌HR的数据边界

角色：品牌公司HR总监。登录名：company_hr_director 或 hk_hr_director。建议时长：3分钟。

说明两个品牌各自管理门店，同时保持集团统一的基础设置与人员主档。

操作路线：人事花名册 / 人事组织架构 / 薪酬管理。

1. 使用香香鱼米品牌HR账号登录，核对顶部范围，查看其下授权内地门店和人员。
2. 退出后使用香港品牌HR账号登录，查看大富烤肉门店及港币薪酬体系。
3. 对照集团HR登录看到的完整范围，说明菜单、人员和字段授权分别限制。不要尝试用隐藏菜单作为数据隔离的唯一证据。

讲解要点：同一页面随角色缩小公司及记录范围。被限制的历史或字段不会由另一个页面自动补回。

## 3 门店店长的排班与核勤

角色：门店店长。登录名：ty000003。建议时长：5分钟。

展示门店班次、颜色、多班段、核勤异常和需要独立发布的排班草稿。

操作路线：排班工作台 / 调班与借调 / 考勤日报 / 考勤月报。

1. 选择2026年10月，打开本店原始基线或已发布版本，切换日时间轴、周班表和月日历。
2. 切换已有画班复制草稿，展示同日多班段与颜色。打开精确输入或批量复制核对窗口后关闭，不在宣传截图时发布新版本。
3. 查看调班或借调记录，比较审批状态和实际应用状态。
4. 打开考勤日报，查看一条缺卡或人工核定记录，再打开月报，对比计划、打卡、在岗和加班分钟。

讲解要点：排满的计划不等于实际出勤。店长和复核人分别负责草稿与发布，已确认历史通过新版本更正。

## 4 门店员工的手机办理

角色：门店店员及档口人员。登录名：ty000001 或 ty000004。建议时长：5分钟。

在手机宽度展示本人排班、假期、学习、申请与工资，不以办公室账号代替门店员工。

操作路线：我的排班与考勤 / 我的假期 / 我的学习与考试 / 我的申请 / 我的工资单。

1. 使用员工本人账号进入手机页面，打开我的排班与考勤，查看当天班段和本人打卡入口。只展示表单，不补造过去的实际打卡。
2. 打开我的假期，查看本人额度和申请状态。展示请假时间、政策及实际关系选择。
3. 进入我的学习与考试，选择可考试或已保存答卷，展示恢复答卷、保存和交卷位置。
4. 打开我的申请，展示调店、住宿与领用入口，查看一笔原申请的审批轨迹。
5. 打开2026年10月本人工资单，说明发布结果与银行到账分别核对。

讲解要点：员工只查看本人资料。阅读提醒不会自动完成业务，已发布工资和待核薪酬保持不同状态。

## 5 内地薪酬核算

角色：薪酬专员及独立复核人。登录名：payroll 加 group_hr_director。建议时长：6分钟。

说明工资项目、公式引用、法定资格、来源净差和批次确认的关系。

操作路线：工资项目与方案 / 薪酬设置 / 工资计算 / 薪税与社保。

1. 打开预置项目目录，展示基本月薪、岗位津贴、绩效、补贴、个人代扣和企业成本的不同类别。
2. 打开一份已核内地工资方案，查看输入变量与项目公式。展示公式引用与单位，关闭详情。
3. 进入10月香香鱼米工资批次，先查看来源，再打开预演与实际工资项目，比较累计目标、原已确认和本次净差。
4. 在薪税与社保查看个税累计期初、社保公积金政策及人员资格。
5. 展示一条因单位工伤浮动费率待补而保留草稿的记录，说明它没有被强行确认或关闭法定项目。

讲解要点：工资方案和当前资料可追溯，待核数据不能用零代替。员工个人代扣与雇主成本分开呈现。

## 6 香港工资与未知工时

角色：香港薪酬HR。登录名：hk_hr_director 或集团授权薪酬人员。建议时长：5分钟。

说明港币、强积金、工资保障和当前已核工时如何共同约束工资计算。

操作路线：工资计算 / 薪税与社保 / 考勤月报。

1. 选择大富烤肉和香港体系，打开10月已确认工资及工资项目，查看个人强积金、雇主强积金和最低保障相关项目。
2. 查看已核工资参数中的工资保障基线和当前考勤来源，说明非工作时间给薪分类需要独立依据。
3. 打开保留未知工时的香港人员月份，显示待核工时及对应待核工资，不将月薪制当作保障豁免。
4. 展示未知工时有据恢复场景的原报告、新核定报告和重新预演记录。

讲解要点：两地规则在各自期间和资格下运行。香港工资项目、供款和工时来源不会直接套用内地配置。

## 7 工资付款与申报核对

角色：薪酬财务复核。登录名：payroll 或 group_hr_director。建议时长：4分钟。

将确认工资、银行支付和机构申报区分开，并展示未知占款的处理。

操作路线：工资付款与申报。

1. 查看应付余额、收款资料和资金期初，说明可申请金额同时考虑已核支付及全部渠道待核占款。
2. 依次展示待审批、已核准、外部未知、部分支付和已核结算的付款记录。
3. 打开申报底稿、目标布局和机构回执核对，说明工作文件与正式受理的区别。
4. 打开一份业务原件，查看原件索引和当前授权下载入口。

讲解要点：V7保留13个资金与申报场景。本演示没有真实付款或官方提交，未知结果保留占款等待有据对账。

## 8 绩效与两套奖金方案

角色：绩效管理员 评分人及员工。登录名：group_hr_director 加评分或本人账号。建议时长：4分钟。

展示评分、复核、发布、申诉与奖金采用之间的状态衔接。

操作路线：考核计划 / 评分与上级复核 / 绩效成绩与申诉 / 绩效与奖金。

1. 打开10月考核计划和参评目标，查看上级评分、互评任务及待复核状态。
2. 进入成绩页，分别展示待独立发布和已经发布的记录。
3. 用本人账号查看已发布成绩和申诉入口，返回HR查看待处理申诉。
4. 在绩效与奖金比较算法A与B的结果、币种和差异，展示正式选择与核准位置，最后说明薪酬还需明确采用。

讲解要点：两套试算并列供客户选择，选择正式版本不表示同一笔奖金重复发两次。

## 9 培训考试与资格奖励

角色：培训专员及员工。登录名：trainer 加 ty000001。建议时长：4分钟。

说明内容、学习、考试、成绩和资格的完整路径，并展示手机恢复答卷。

操作路线：课程与培训内容 / 培训计划与学时 / 题库与考试 / 阅卷成绩与申诉 / 岗位资格与结果应用。

1. 查看课程和培训计划，展示岗位或品牌范围指派以及学时、签到和纪律记录。
2. 用员工账号进入我的学习与考试，查看可考任务、限时和已保存答卷。
3. 用培训账号查看主观题待阅卷、重考后通过和成绩待发布记录。
4. 打开岗位资格与结果应用，查看核准标准、资格有效期和两地薪酬奖励候选。

讲解要点：培训纪律不自动变成工资罚款。学习完成、考试通过、成绩发布及奖励核准分别办理。

## 10 招聘合同与到期门户

角色：招聘专员及HR。登录名：recruiter 加 group_hr_director。建议时长：4分钟。

展示需求到入职，以及合同待遇、到期提醒与员工主档的关联。

操作路线：招聘管理 / 入转调离 / 人事合同 / 合同到期提醒。

1. 查看待审招聘需求、新候选和面试任务，打开已复核的简历原件。
2. 查看录用及入职衔接记录，说明系统先查既有永久人员再建立新雇佣。
3. 打开人事合同，查看签约主体、有效期、待遇与生效记录。
4. 进入合同到期提醒，展示已读和实际办理状态的区别，说明续签草稿不会提前终止旧合同。

讲解要点：外部招聘网站和电子签未使用真实凭据实连。演示采用本地原件、结构化复核和审批。

## 11 宿舍证件与行政领用

角色：普通HR 宿舍及证照管理员。登录名：hr_staff 或 group_hr_director。建议时长：5分钟。

覆盖餐饮人员流动所需的房源床位、健康证件和福利领用。

操作路线：宿舍管理 / 证件证照 / 物品领用 / 员工全貌。

1. 点击一处房源，查看房间、床位、租金、在住人员和维修影响。
2. 打开转房或退宿申请，检查审批和实际交接，再查看租金水电源账单与个人费用。
3. 进入证件证照，展示门店证照、员工健康证、应持证要求及将到期记录。
4. 进入物品领用，展示采购入库、领用用途、福利发放和实际出库。
5. 从人员进入员工全貌，确认住宿、证件和领用记录均关联同一人。

讲解要点：这些配套功能采用简明表单和审批。宿舍费用、非现金福利及领用统计不会擅自改写已确认工资。

## 12 外包HR供应商与服务人员

角色：外包HR 供应商联系人及外包员工。登录名：outsource_hr 加 vendor_cn 加本人服务账号。建议时长：6分钟。

将实际服务量、供应商对账资金和员工本人沟通串成同一业务线。

操作路线：供应商与用工 / 服务量与对账 / 供应商资金 / 用工沟通。

1. 查看已核资格、服务合同、订单及原服务人员，说明永久编号、法律雇主和工作门店分别保存。
2. 查看11月16日三段服务和截至17日的核定总量，打开按360分钟折6小时计价的对账明细。
3. 用供应商账号查看自己已共享的账单，展示同意、异议或等待确认的状态。
4. 返回HR查看应付与付款未知，说明生成底稿、供应商收款和员工到账分别核定。
5. 用服务员工本人账号打开共享沟通并回复。对照HR看到的内部复核备注，说明员工和供应商不会看到内部内容。

讲解要点：后续未发生日期保留待核；10月直营经历不重复计入11月外包服务。外包资金与员工工资避免重复计成本。

## 13 老板的人力成本

角色：老板。登录名：boss。建议时长：3分钟。

从授权成本总额看到公司、门店、人员及项目的来源。

操作路线：人力成本 / 人事组织架构 / 人事花名册。

1. 选择集团范围和2026年10月，分别查看人民币与港币成本，不在缺少汇率时混成一个总数。
2. 从成本查看批次、人员和项目，区分工资、企业供款、福利和外包服务。
3. 回到组织架构和编制，查看门店人员及满编超编情况，说明编制、出勤和成本的关联。

讲解要点：老板使用只读经营视角，不代替HR核定、独立复核或财务付款操作。

## 14 系统管理员的权限审批与集成

角色：系统配置管理员。登录名：admin。建议时长：6分钟。

展示功能、数据、字段权限，表单与审批流设计，以及三平台连接的配置边界。

操作路线：操作人员与权限 / 表单设计 / 审批流设计 / 连接与接口对账 / 同步打卡与消息。

1. 打开操作人员与权限，查看账号、角色、成员及完整授权。使用只读模拟，核对组织范围和拒绝字段。
2. 打开表单设计，查看发布版本、字段及预览，再查看审批流节点、条件、处理人、通知及业务绑定。
3. 查看已有流程实例，区分审批轨迹和实际办理状态。
4. 打开钉钉、飞书和企微连接，展示未配置凭据和能力核对入口。
5. 打开文件打卡接入，查看来源文件、身份对照、收件箱和HR归属核查，说明核准原卡还需进入新核勤版本。

讲解要点：配置管理员不因能够设计权限而自动获得薪酬、银行或人事业务操作权。未配置连接不显示为已经实连。

## 结束与恢复

演示后退出各角色账号，保留原操作号及业务版本。出现结果未知先核对原提交，不另起同类重复操作。需要重新演示已经完成的状态时，从独立备份恢复到新演示库，不覆盖原确认历史。
