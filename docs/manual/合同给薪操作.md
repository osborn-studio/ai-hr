# 合同条款进入工资核算

入口：**薪酬管理 → 合同给薪核定**。在 **招聘管理 → 人事合同 → 合同条款** 中，也可由有效条款行的“给薪核定”直接进入，自动带入合同与条款，无需抄写编号。手机使用同一入口，以卡片展示。

## 先核对原条款

合同须有已登记的签署原件，条款须独立复核并正式生效。原条款保留金额、币种、单位、有效期、真实工作关系与法律主体。系统不会把待签合同或待核金额自动当作工资。

“有效合同条款”页选择**工资采用月**，查看原合同、员工永久编号、实际公司、工资项目和有效区间，再点击“建立给薪核定”。工资采用月对应工资批次所属月，银行支付日期、个税和供款期间仍在薪税配置中分别核定。

## 建立核定并由另一人员复核

选择同公司、本期有效且已核准的工资方案，明确采用性质：

- **公式输入参数**：选择该方案真正使用的输入变量及其单位。合同基本月薪替代同一基薪公式输入，保留原工资档案；不能将参数再当成一笔现金。
- **现金义务**：用于明确的一次性或按期待遇。选择原工资项目，并按已核工资方案明确平均工资、年假工资和正常工资分类；不得与同项档案公式重复发放。

填写待遇归属开始日、结束日（结束日不含）、明确的整数折算分子和分母，以及依据。整月1比1也须明确填写，系统不会猜测折算比例。缺少的原金额只能在支持的参数场景有据核定，已知原金额不能被随意手填覆盖。

保存后为“待独立复核”。经办人、同一自然人的其他账号以及受益员工本人不能复核。另一名有完整字段和范围权限的人员核对原合同、工作关系、期间、单位、项目、折算和依据后，点击“独立复核”。核准仍不产生工资或银行支付。

## 工资预演、采用与确认

进入 **薪酬管理 → 工资计算**，建立相同公司、体系、币种、方案和工资采用月的批次。

1. “选择来源”中，选择员工工资档案及同一工作关系的已核合同参数；独立现金待遇另行选择。
2. 点击“预演工资与法定项目”，核对每项累计目标、原已确认和本次净差。合同参数只改变原公式输入，不出现另一条基薪现金。
3. 由另一人员在“预演与采用”独立复核；经办人采用到工资。
4. 由另一人员复核确认工资，再在“实际工资项目”查看应发、代扣、净工资和来源。工资单发布、银行付款分别办理。

有效合同基本工资或已核按期待遇不能通过漏选来源而静默消失；没有完整映射时系统会阻止普通工资预演/确认。当前不提供“忽略合同继续旧档案”的快捷操作。若确需另行处理，应先依法办理合同或给薪核定版本并保留独立复核依据。

## 更正与历史

同一义务按累计目标减去原已确认工资及当前占用，仅采用净差。一次性待遇跨采用月仍沿同一义务，不重复发放；按期待遇按归属月分别核对。月中变更的多个参数片段必须完整覆盖实际在职区间，不能重叠或缺段，分数相加后再处理金额精度。

原合同、原件、工资档案和已确认工资不回写。合同或映射版本变化后，旧预演会失效，需要重新预演和独立复核。核定页区分“未采用”“已采用待工资确认”“已形成已确认工资”，不要把已核准误认为已入薪。

香港使用HKD及香港工资体系；内地使用CNY及内地体系，不自动兑换币种。香港平均工资、强积金和内地个税社保仍受各自工资规则和资格校验约束。

## 演示资料与验证范围

完整新演示工厂增加11月3个场景：内地已核合同参数、香港已核合同参数、待独立复核参数。此场景仅新建核定及所需本期配置，不产生11月工资，不修改10月原工资或原合同。

独立开发验收实际走通了原合同条款 → 映射核定 → 独立复核 → 原生工资预演 → 采用 → 独立确认 → 工资明细：基薪15000与另项餐费300，真实工资项目合计15300。该金额来自隔离验收数据，不代表客户工资或已完成银行支付。
