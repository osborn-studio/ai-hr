# 天意人力资源系统 V11 修订说明

2026年11月17日。本次修订改善组织图操作和菜单查找，并补充绩效、培训与考试场景。本说明与基础资料V10合并使用。

## 组织图宽度调整

打开“人事管理 → 人事组织架构”。组织图与人员详情中间新增可拖动的分隔条，左侧默认占52%，可根据查看内容调整到30%至70%。

把鼠标放在中间分隔条上，按住并左右拖动。查看多层部门和长门店名称时向右拖；需要查看关联人员明细时向左拖。双击分隔条恢复默认宽度。

使用键盘时，按Tab选中分隔条，用左右方向键微调，Home和End切到最小及最大宽度。浏览器会记住本机的宽度；手机等窄屏继续上下排列。树状和网状组织图共用此布局。

## 菜单顺序

左侧导航从上到下依次为“我的工作台”“我的办理”“人事管理”“薪酬管理”，其后保留其他业务模块。人事管理为第一个业务管理模块。

我的办理集中放置本人排班与考勤、学习与考试、绩效、工资单、待办、申请和提醒。各账号仍只显示当前获授权的入口，菜单排序不会增加权限。

## 蓝白金界面层次

界面保留白底内容区，以蓝色渐变导航和标题强化功能层级，卡片及按钮增加阴影，香槟金用于指标强调线和选中导航。表格继续使用清晰白底，方便核对人员与工资。

## 绩效演示场景

新增4个绩效计划，覆盖48个人员考核目标与48份评分任务；已形成44份评分、40份结果和32条已发布成绩，并保留待评分、待审核及未发布状态，方便讲解完整办理过程。

从“绩效管理”进入考核计划，按计划名称和状态查找新增计划，查看不同门店人员的目标与评价关系。打开评分任务，比较未评分、已提交待复核和已复核的状态。

进入绩效结果，查看待核准与已发布的成绩，穿透人员档案核对对应永久人员编号。已发布成绩可由本人门户按权限查看。

新增计划不生成奖金试算、奖金义务或工资采用行；需要发放奖金时仍按原有双算法试算、独立核准和薪酬采用流程办理。

## 培训考试演示场景

新增6门课程、6个培训计划、24道题目、6份试卷和6场考试，覆盖72条考试任务、54条培训出勤、54次作答与36份成绩，包含通过、未通过和待审核等场景。

从“培训与考试”进入课程和培训计划，比较不同门店的参训人员、出勤状态及学习内容；在人员全貌中查看已形成的学习记录。

打开考试管理，按考试状态查看考试任务、试卷和题目，再查看已作答、待审核、已发布及通过或未通过的成绩。

使用员工账号进入“我的办理 → 我的学习与考试”，查看本人任务与获准发布的成绩。需要演示作答和阅卷时在独立副本操作，保留原演示状态。

## 阅读与演示方法

先看本修订说明了解新增操作和场景，再按基础资料V10中的完整操作手册与分角色演示路线浏览其他模块。基础资料保留原V10版本名、原截图和验证说明；本次修订没有把旧图标记成新界面。

组织、人员和账号仍为天意集团、香香鱼米与大富烤肉，20家门店、62名人员、77个账号。新增场景沿用既有人员身份；客户资料没有导入本帐套。原工资、考勤与历史记录保留。

要展示有状态变化的提交、审核和考试作答，请先制作独立演示副本。绩效成绩发布、奖金核准、工资采用及实际付款分别办理；新增样例不自动入薪或对外付款。
