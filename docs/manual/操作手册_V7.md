# 天意人力资源系统操作手册

本手册供天意人力资源系统V7本地演示环境使用，按实际菜单和已实现的操作说明各模块的办理方法。演示使用天意集团、香香鱼米、大富烤肉及62名人员，包含集团总部、品牌公司、门店与外包服务场景。资料和截图不含客户真实数据。外部平台未配置的连接、银行实际支付和官方申报结果不会写成已经完成。

账号及口令由管理员另行提供，详见本地账号手册。

## 1 登录与工作范围

入口：我的工作台。适用角色：所有操作人员。

先使用管理员分配的账号登录。系统按角色显示入口，页面顶部的集团、品牌公司和门店决定当前浏览范围。门店人员从本人门户办理日常事项。

1. 登录后确认右上角身份，再确认顶部集团与公司范围。切换范围后，等待页面完成刷新。
2. 在左侧展开业务分组，通过二级菜单进入页面。手机点左上角菜单；底部提供工作台、人员、薪酬或搜索等获授权快捷入口。
3. 点击查找功能与页面，输入花名册、月报、工资等关键词。搜索结果只列当前账号可进入的页面。
4. 列表搜索用于收窄当前业务记录。每页条数和上一页、下一页用于翻页；改变搜索条件后从第一页重新查询。
5. 单击详情、员工姓名或员工全貌，可以查看来源记录。敏感字段和原件下载仍按当前权限重新核验。

办理结果：同一账号可见的菜单、公司、人员及字段分别受控。功能账号与员工自助账号可以关联同一永久人员。

使用说明：账号及初始口令见本地账号手册。本资料不包含口令。demo用于全部功能演示，admin用于系统配置；正式使用应设置独立账号。

## 2 集团品牌公司与门店基础

入口：人事管理 / 人事组织架构。适用角色：集团HR总监及组织管理员。

帐套可以覆盖集团，集团下建立品牌公司，再管理各门店。门店作为独立公司记录，不用部门代替核算主体。集团、品牌公司及门店都可以设置部门和岗位。

1. 使用新建集团帐建立集团范围，并在同一集团内维护品牌公司。新品牌通过创建品牌公司建立上下级关联。
2. 点击新增组织或岗位，先选所属公司，再维护部门、岗位与档口。档口可关联部门或工作区域，岗位保持厨师、服务员、店长等通用定义。
3. 为组织和岗位设置有效日期。人员当前任职通过公司、部门、岗位、职级共同描述，历史任职保留原有效期间。
4. 更改设置后进入待复核版本，由另一名获授权人员独立复核发布。核准状态与实际生效日期分别查看。

办理结果：天意集团下包含香香鱼米和大富烤肉，各有10家门店。大富烤肉门店使用香港地区与港币场景。

使用说明：组织上下级、法律雇主、发薪主体及成本承担分别记录。不能仅凭品牌归属推断实际法律关系。

## 3 组织架构图与编制

入口：人事管理 / 人事组织架构。适用角色：集团HR 品牌HR 店长及老板。

树状组织图用于逐级展开，网状组织图用于查看组织关联。组织节点可以进入人员明细，编制与空缺页核对部门和岗位容量。

1. 切换树状组织图或网状组织图，选择要查看的公司、部门或岗位节点。
2. 打开节点详情，查看所属关系、岗位和当前人员，再进入员工全貌核对任职。
3. 切换编制与空缺，按部门或岗位范围查看核定人数、FTE、在岗人数、招聘占用和剩余名额。
4. 需要调整时点击核定编制，填写范围、有效期间和核定依据，提交独立复核。
5. 分别检查满编、超编和有空缺的记录，确认招聘需求采用正确公司及岗位编制。

办理结果：编制记录与人员任职、招聘占用使用同一组织基础。图中人数按当前日期及授权范围计算。

使用说明：组织图是查看入口，编制核定是有版本的业务操作。老板账号以只读查看为主。

## 4 人事花名册与员工全貌

入口：人事管理 / 人事花名册。适用角色：集团HR 品牌HR 普通HR及授权店长。

一个人保留同一集团内的永久人员编号。入职新门店、跨品牌任职及离职后再入职，新增实际雇佣经历，沿用原人员主档。

1. 使用姓名、永久编号或关键词搜索花名册，在全部人员、当前在职、历史雇佣、待入职之间切换。
2. 点击显示字段，选择本次需要的列。Excel导入先下载或核对当前模板，上传后检查预检结果，再提交执行。
3. 点击姓名进入员工全貌，核对个人资料、各公司任职、部门岗位和入离职时间。
4. 继续查看合同、考勤、假期、绩效、学习考试、证件、住宿及领用等已关联记录。业务来源各自保留状态，尚待核定的记录保持待核。
5. 跨店历史统计与福利发放优先用永久编号识别，不用姓名或当前门店编号重新创造人员。

办理结果：集团HR总监可在授权集团内查看跨品牌完整经历，品牌与门店账号查看各自授权片段。

使用说明：人员主档、账号、实际雇佣及岗位任职是不同记录。查看历史不会将同时存在的合法关系合并成一份工资。

## 5 入转调离与多店任职

入口：人事管理 / 入转调离。适用角色：集团HR 品牌HR及普通HR。

入职、转正、调动及离职从统一办理单发起。人员编码保持连续，组织和薪酬按核定日期接续。

1. 选择人员后发起人事办理，明确办理类型、生效日期、原公司与目标公司。
2. 新入职先核对既有人员是否已存在。跨店或再次入职选择原人员主档，录入新的实际关系及合同资料。
3. 部门岗位调整填写目标部门、岗位和职级，待遇变化按相应来源另行核定。
4. 提交后检查核准状态及实际生效。流程获批后仍须核对业务是否已经执行，不以阅读提醒代替实际办理。
5. 完成后回到花名册及员工全貌，确认原关系结束日、新关系起点和岗位历史。

办理结果：入离职经历、合同待遇和工资计算可以按有效期间相互核对。演示中保留同人跨品牌、跨门店及多次入职记录。

使用说明：调班和门店借调在排班考勤办理；实际法律关系变更在人事办理，不用修改一条当前门店字段覆盖过去。

## 6 招聘需求到入职

入口：招聘管理 / 招聘管理。适用角色：招聘专员 面试官及集团HR。

招聘从编制需求开始，连接候选资料、面试、录用及入职办理。候选人转为员工后继续使用统一人员和任职记录。

1. 建立招聘需求，选择公司、部门、岗位、人数与目标日期，检查编制占用。
2. 录入候选资料，上传简历原件或按模板导入。打开简历复核，确认识别或整理后的字段，不以文件上传代替内容核对。
3. 安排面试轮次、面试时间和评价人，面试官在获分配的任务中提交评分与结论。
4. 录用前核对拟入职日、岗位和薪资条件。按相应审批办理录用，生成后续入职来源。
5. 在人事办理中执行入职，再检查花名册、任职和人事合同。原简历、面试和录用记录可以追溯。

办理结果：V7提供需求待审、新候选、面试、录用和入职衔接等不同状态的演示记录。

使用说明：招聘网站和外部电子签尚未使用真实客户凭据实连。当前可通过原件、Excel和人工复核完成本地流程，不宣称已自动同步外部网站。

## 7 合同待遇与到期提醒

入口：人事管理 / 人事合同及合同到期提醒。适用角色：HR 合同管理员及获授权员工。

合同保存签约公司、有效期间、原件和结构化待遇。基本工资、奖金或考勤待遇条款核定后，按明确生效操作传入对应业务来源。

1. 在人员或合同列表新建合同，选择员工实际关系、签约公司、合同性质及起止日期。
2. 上传合同原件，核对工资、奖金、工时和其他待遇字段。附件保存与待遇字段确认分别办理。
3. 按当前状态完成签署核对、独立复核和生效。待遇来源查看计薪来源、来源金额及实际生效日。
4. 打开合同到期提醒，按到期日和公司筛选。提醒记录区分阅读与办理进度，续签草稿不会提前关闭原合同。
5. 办理续签、变更或终止后，回到员工全貌核对原合同、新版本和有效期间。

办理结果：HR和员工门户可查看各自授权的提醒与合同。合同待遇影响后续工资时仍须正常核算和复核。

使用说明：本地原件和签署核对记录不表示已通过外部电子签服务完成法律签署。外部接口须配置并核对真实回执。

## 8 高级排班与手动画班

入口：排班考勤 / 排班工作台。适用角色：店长 考勤专员及集团HR。

原始基线只读，编辑从新建排班草稿开始。日时间轴、周班表、月日历提供不同观察范围，一天允许安排多段班次。

1. 选择2026年10月及工作日，确认公司范围和排班版本。点击新建排班版本，由已有版本复制或建立新草稿。
2. 切换日时间轴，在手动画班模式拖出班段；调整画线吸附分钟，或点精确输入填写开始、结束和休息段。
3. 在选择与移动模式选择班段并拖动。按Ctrl拖动用于复制（Mac也支持Option）；提交前核对本次复制或移动的目标人员、日期与时间。
4. 选择多个班段后点击复制到其他日期，核对跨夜时间、一天多班次、休息安排及重叠提示。
5. 在班次设置新增班次、休息段和颜色。颜色图例用于区分早班、晚班、收尾或其他班型。
6. 草稿完成后交另一位有权人员复核发布。手机以人员班段卡片查看，复杂画线操作使用PC。

办理结果：发布的排班供打卡比对、请假量计算和核勤取数。变更以新版本保留原计划。

使用说明：排班是计划。实际工时需要打卡或有据核定，不能把排满的班次当作已经出勤。

## 9 打卡调班与门店借调

入口：我的办理 / 我的排班与考勤及排班考勤 / 调班与借调。适用角色：门店员工 店长及考勤专员。

本人打卡、员工换班、个人调班和门店借调保留不同来源。调班审批与最终应用分开，接收门店服务记录不会重复造一份雇主工资。

1. 员工在我的排班与考勤查看自己的班段，点击本人打卡，核对实际关系、班段与方向后提交。
2. 通过调班或借调申请填写原班段、目标安排、借调门店及原因。需要对方确认时等待原对方处理。
3. 店长或HR在调班与借调查看内容与差异，按当前审批状态办理。
4. 获批后检查实际应用状态，核对是否生成排班草稿、是否已按规则发布，以及人员所属和实际工作门店是否正确。
5. 迟传和补充的原卡通过来源接入核查或有据更正处理，原始发生时间保留。

办理结果：演示包含待对方确认、待审、驳回、获批待应用和已更正等记录。

使用说明：钉钉、飞书、企微或设备来源需要另行配置对照。当前本地打卡与外部原卡分开留痕。

## 10 HR考勤日报月报与版本

入口：排班考勤 / 考勤日报及考勤月报。适用角色：考勤专员 店长及薪酬专员。

HR核勤同时查看计划、实际打卡和核定结果。缺失证据保留未知值，核勤更正生成另一版本，原确认版本仍可查看。

1. 选择月份、工作日和核勤版本，按姓名、永久编号或公司筛选。日报查看每人每天，月报查看员工月份汇总。
2. 打开原值与明细，比较计划工时、实际打卡、核定在岗、加班、迟到早退和缺卡。
3. 需要人工更正时新建核勤草稿，点核定调整，录入实际值、原因和证据引用；不要把未知值随意填零。
4. 另一名有权限人员复核确认本版本。工资取数采用该员工月份当前有效的雇主口径核勤根，过期来源会阻断采用。
5. 导入Excel先预检。日报导入与月汇总导入分别选择；月汇总不生成并不存在的逐日打卡。
6. 使用导出Excel交付HR核对表，在版本记录中追溯新旧报告。

办理结果：原值、调整值和当前有效版本能够相互核对。内地与香港工资使用各自适用的已核数据。

使用说明：跨店工作地分摊用于核对成本，不能将雇主汇总与接收门店视图相加。

## 11 高级假期与人工核定

入口：排班考勤 / 假期台账及假期设置。适用角色：假期管理员 HR及员工本人。

政策版本、实际关系、额度批次、申请占用和实际已休分别记录。规则提供人工核定入口，用于补充地区、人员资格或原始证据尚不确定的情形。

1. 在假期设置查看地区、政策性质、单位和有效期。新建或修订政策后，由另一位有权限人员复核发布。
2. 在假期台账核实人员实际关系，再按政策发放额度或维护有据期初。打开账户查看可用、占用和已休。
3. 员工在我的假期选账户、政策和实际公司关系，填写开始、结束时间和证明引用。系统按政策与已发布排班核算数量。
4. 审批后先保留占用，HR按实际情况核定已休。取消、驳回、过期及退回沿原额度血缘处理。
5. 额度需要调整时先保存预演意图，由另一人检查基线后生效。法定负向更正和到期处理保留专门依据。
6. 给薪候选需要明确工资目标和普通工资已覆盖量，再进入正常薪酬采用，防止重复给薪。

办理结果：演示包含内地与香港年假、病假、多班次分钟核量、人工调整和给薪净差。产假、育儿假等模板保留待补资格或地区条件的状态。

使用说明：模板待核不等于规则已经发布。当前假期直接申请使用证明引用；原件上传应通过已接入的资料或申请表入口，不宣称此表已自动上传附件。

## 12 两地薪酬体系与工资项目

入口：薪酬管理 / 薪酬设置及工资项目与方案。适用角色：薪酬专员及薪酬配置管理员。

公司和门店可以启用中国内地、香港一种或两种体系。每份实际关系选择适用方案、币种和有效期间，工资项目不只是一张固定工资表。

1. 在薪酬设置选择体系、公司和配置类别，维护实际雇主、发薪主体、普通工资参数及工资日历等资料。
2. 选择工资方案，设置变量来源与单位，新增工资项目并填写公式。公式引用其他项目时按依赖顺序计算，循环或单位不符会阻断。
3. 查看预置工资项目目录，按合同和经营需要选择基本月薪、岗位津贴、餐费交通、绩效等项目。法定义务按资格核定，不随可选项目开关关闭。
4. 为绩效、培训奖励、假期给薪、宿舍及其他来源配置采用待遇和归属规则。参数或规则变更建立新修订。
5. 检查来源、公式和适用期间，由另一位有权限人员复核发布。

办理结果：目录预置134项供方案配置。普通金额、参考基数、非现金福利、法定个人代扣和企业成本分别表示。

使用说明：没有核准的规则、资格或来源不能以零代替。地区、有效期和真实法律关系决定实际适用。

## 13 工资计算与来源采用

入口：薪酬管理 / 工资计算。适用角色：薪酬专员及独立复核人员。

工资汇总合同待遇、已核考勤和各业务核准结果。选择来源、预演、独立复核、采用、工资确认和工资单发布分别办理。

1. 选择发薪公司、工资月、内地或香港体系，建立常规、补发、更正净差或仅成本批次。选择已核真实关系和工资方案。
2. 点击进入核算，在选择来源中核对薪资档案、核勤、绩效奖金、培训奖励、假期和住宿费用等当前可用来源。
3. 选择适用的薪税与参保资格，生成工资与法定项目预演。逐项查看累计目标、原已确认和本次净差。
4. 由另一位有权限人员独立复核，或送审批流；通过后采用到工资，再复核确认批次。
5. 在实际工资项目中核对应发、个人代扣、净工资应付、企业成本和每项来源。
6. 发布工资单后，员工在我的工资单查看本人结果。付款和外部申报在工资付款与申报单独处理。

5. 审批完成后查看实际办理状态，确认领域业务已经应用，不能用一个通用已通过标签覆盖资金或现场交接。

办理结果：表单、流程和业务来源分别保留版本。新增审批设置影响后续新提交，历史实例按原版本追溯。

使用说明：通知接收人、审批人和业务执行人承担不同职责。收到提醒或点击已读不代表完成审批或业务执行。

## 27 钉钉飞书企微与考勤接入

入口：集成设置 / 连接与接口对账及同步打卡与消息。适用角色：集成管理员及授权HR。

连接配置、组织人员对照、来源收件箱、打卡归属和消息投递分别管理。配置界面会明确未配置、待核、成功或结果未知。

1. 新增钉钉、飞书、企业微信或设备连接，维护应用信息、组织标识和凭据。凭据只在受控服务器保存。
2. 维护组织和人员对照，人工确认对应的本地公司、永久人员及实际雇佣。不要按同名直接合并身份。
3. 配置采集和通知规则，独立核准应用用途。外部原卡保留稳定流水号、原始时区、发生时间及验证方式。
4. 在来源收件箱关联到具体班段，由另一HR核准。Excel原卡先预检和独立导入，再归属核查。
5. 核对回传与投递日志。结果未知先回读对账，不标成外部已接受或重复投递。
6. 有权人员把核准来源纳入新的核勤草稿，再按正常复核形成当前有效结果。

办理结果：V7提供三平台未配置连接、内地及香港文件接入、待归属和已核来源、无效时区等场景。

使用说明：演示没有真实平台凭据或外部消息发送。组织同步、SSO及第三方应用模式以实际已配置能力和回执为准，不笼统承诺所有外部接口已实连。

## 28 人力成本与月度核对

入口：数据报表 / 人力成本。适用角色：老板 集团HR及授权财务人员。

老板按授权范围查看已确认成本。工资、企业供款、福利和外包服务成本保留来源，供应商代发资金不重复充当另一份工资成本。

1. 选择集团、品牌或门店范围，选择工资月，按体系和币种分别查看结果。
2. 从成本汇总穿透到批次、人员及项目，核对工资归属、成本承担和来源版本。
3. 结合考勤月报检查缺卡、未知工时和人工核定，结合绩效奖金及培训奖励检查是否已正式采用。
4. 检查宿舍费用、非现金福利、外包服务量和应付是否按明确用途计入，避免把员工代发资金重复计成本。
5. 按现有列表筛选与Excel导出交付核对结果，保留所用月份、公司范围和版本。

办理结果：数据报表反映当前授权已确认业务，待核或未采用事项保持自己的业务状态。

使用说明：不同币种未配置汇率时分别展示。当前不宣称已经提供任意拖拽式自定义BI报表设计器。

## 29 HR月结操作顺序

入口：跨模块月度工作。适用角色：集团HR 考勤薪酬及财务复核。

月结先确认人员与组织，再核勤、业务结果和工资，最后核对支付与成本。每一步保留可复查来源。

1. 核对本月人员入转调离、实际雇主、合同待遇及参保纳税资格，确认期间和人员编码连续。
2. 发布最终排班，处理调班借调和原卡，核定考勤日报及月报。未知工时保留待核，不强行关闭异常。
3. 完成假期实际已休、绩效正式奖金、培训奖励、住宿费用等核准，明确哪些进入工资和哪个发放月。
4. 按公司和体系预演工资，独立复核后采用和确认，发布个人工资单。
5. 核对收款资料、资金期初、付款占用与机构结果；工资、外包及员工代发渠道共同核对余额。
6. 查看人力成本和待核清单，导出核对资料，备份系统并保留版本。

办理结果：月结交付包括考勤日报月报、工资项目与工资单、付款申报核对、外包对账及成本来源。

使用说明：重新打开已确认期间必须有明确更正来源和权限。更正保留旧版与本次净差，不覆盖原历史。
