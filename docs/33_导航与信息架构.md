# 33 · 导航与信息架构

> 一句话：**先回答"这件事属于哪一块"，再回答"具体是哪个页面"。**

## 1. 改之前是什么样

28 个页签平铺成一行，靠一个分隔条分成三组（日常业务 / 配置与规则 / 系统）。
问题不是"太多"，而是**层级被抹平了**：

- 「制度」和「算薪」看起来一样重要 —— 而一个一年看两次、一个每月必用；
- 「薪酬政策」和「建帐」挨着，但一个属于薪酬域、一个属于开户；
- 新加页签只能往队尾追加，越加越像一串没有结构的清单。

## 2. 现在的结构

11 个一级，按**真实上手顺序**排，不是字母序：

| 一级 | 二级 | 为什么在这一组 |
|---|---|---|
| **我的** | 工作台 · 待办审批 · 我的权限 | 每天打开先看这里；与"管别人"无关 |
| **系统管理** | 建帐 · 员工档案 · 制度 · 例外 · 自检 | 上线第一天要做的事：开帐、把人加进来 |
| **人事组织** | 组织架构 · 编制 · 离职结算 | 组织结构与人员进出 |
| **考勤排班** | 打卡 · 排班 · 考勤人日 · 考勤报表 · 考勤封账 | 一条链：排了班才打卡，打卡汇总成人日，人日汇总成月报，月报封账才能算薪 |
| **假期** | 年假与折现 | 额度、结转、折现；请假单从考勤与审批进，额度在这里结 |
| **薪酬** | 算薪 · 工资条 · 工资调整 · 工资项 · 薪酬政策 · 外包结算 | 发钱这条线；**薪酬政策是这里的一个二级**，不是独立大项 |
| **招聘** | 招聘 | 独立域，只有一项时点击直达 |
| **绩效** | 绩效 | 同上 |
| **培训学习** | 培训学习（规划中） | 占位，见下 |
| **看板** | 数据看板 · 报表 | 看趋势与导出对账，与"操作"分开 |
| **AI 智能** | 开放层 | 给 AI 用的工具与接口 |

### 一级的顺序为什么是这样

真实上手路径就是这一条：**先建帐 → 再加人 → 才排班打卡 → 才算钱 → 才看数**。
把「看板」放在「薪酬」前面好看，但会让第一次用的人找不到"从哪开始"。

## 3. 几处刻意的决定

**① 只有一个页面的分组，点击直达，不弹菜单。**
招聘、绩效、培训、AI、假期都只有一项。点开一个只有一行的菜单比直接跳过去更慢，
而且会让人怀疑"是不是还有别的没显示"。

**② 二级项带一句说明。**
下拉里只有四个字「工资调整」，等于没解释。加一行小字（"调薪单、按月版本"）之后，
这个菜单才能回答"我该点哪个"。

**③ 薪酬政策降级为二级。**
它原来是一级（和「算薪」平级），但它本质是**薪酬的参数**：
社保上下限、个税阈值、节假日、工时制度 —— 都是"给算薪用的配置"。
放在「薪酬」下面，「改参数 → 看预演 → 算薪」这条动线才连得上。

**④ 培训学习先占位，但不编数据。**
菜单里有、点进去空着，比没有这个菜单更糟 —— 人会以为"功能坏了"。
所以这一页写的是"要做需要哪三样东西、按什么顺序做"，而不是摆几张假课程卡片。

## 4. 实现要点（踩过的坑）

| 坑 | 现象 | 做法 |
|---|---|---|
| 下拉塞进横滑容器 | 手机上点了菜单，DOM 里 rect 正确、**画面上什么都没有** | `.tabs` 只做定位容器；横滑交给 `.navrow`；下拉放进独立的 `#droplayer` |
| `overflow-x:auto` 的祖先 | 会成为 absolute/fixed 后代的裁剪容器 | 同上，且下拉用 `position:absolute` 相对 `.tabs`（不吸顶时不会跑） |
| `backdrop-filter` | 为 fixed 后代创建包含块，等于额外裁剪风险 | 吸顶条设 `backdrop-filter:none`（本来就不透明） |
| 在 `renderTabs` 里注册 document 监听 | 每次重渲染加一个，点一下跑 N 次（"偶尔要点两次"） | 监听器只注册一次，放模块顶层 |
| 新页签忘了登记分组 | 页面还在，但菜单里找不到（表现为"功能没了"） | `renderTabs` 里算 `orphan`，直接红字挂在导航上；界面断言钉住"没有未归类页签" |

## 5. 加一个页签的正确姿势

1. `TABS` 里加一条（`key` / `name` / `desc`）；
2. `GROUPS` 里挂到某一组的 `items`；
3. `load()` 里加一个分支；
4. `ui.test.mjs` 的页签清单里加一行（每个页签都要被渲染过一次）。

漏了第 2 步不会静默 —— 导航上会红出「未归类的页签：xxx」。

## 6. 断言

`UI28` 钉的是**结构契约**（下拉内容是点开才渲染的，dumpDom 不执行点击）：

- 一级 11 组、名字与顺序正确；
- 分组条目数：薪酬 6、考勤排班 5、系统管理 5，招聘/绩效/培训/AI 各 1；
- 有多项的分组带 `caret`（下拉箭头），单项组不带；
- `#droplayer` 容器存在；
- **没有未归类页签**（`nav-orphan` 不出现）。
