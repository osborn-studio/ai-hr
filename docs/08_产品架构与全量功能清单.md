## 第一部分：产品架构

### 1.1 一句话定位

面向连锁餐饮集团的**全模块人力资源平台**：把「组织—人事—排班—考勤—假期—薪酬—招聘—绩效—学习—用工—外包」连成一条链，并以 MCP 协议开放给任何 AI 调用。

### 1.2 四层架构

```
┌───────────────────────────────────────────────────────────────┐
│ L1 接入层                                                       │
│   PC 浏览器 ｜ 手机 H5 ｜ 协同平台内嵌 ｜ 门店平板 ｜ MCP 客户端    │
├───────────────────────────────────────────────────────────────┤
│ L2 应用层（按角色组织的工作台）                                    │
│   集团工作台 ｜ 区域工作台 ｜ 门店工作台 ｜ 员工自助 ｜ 供应商门户    │
├───────────────────────────────────────────────────────────────┤
│ L3 业务域（15 个域，见第二部分）                                  │
│   组织编制 · 人事 · 排班 · 考勤 · 假期 · 薪酬 · 社保个税            │
│   招聘 · 绩效 · 学习考试 · 灵活用工 · 外包协同 · 报表 · MCP · 平台  │
├───────────────────────────────────────────────────────────────┤
│ L4 数据层                                                       │
│   事实层(punch) → 结果层(daily) → 归属层(区间表) → 视图           │
│   配置层（参数集/政策包/规则）· 快照层（8 项）· 审计层              │
└───────────────────────────────────────────────────────────────┘
```

### 1.3 核心业务链（一条主线贯穿）

```
开店/定编 → 招聘/入职 → 排班 → 打卡 → 异常处理 → 出勤确认
   → 封账 → 算薪 → 工资条 → 成本分摊 → 门店人效/毛利
```

三个跨域贯穿点：
- **工时**：排班计划工时 → 实际工时 → 计薪工时，一条事实源
- **组织**：四维归属贯穿考勤、薪酬、成本、绩效
- **权限**：功能 × 数据范围 × 字段级，MCP 与 Web 同权

## 第四部分：一期交付边界

**一期（P0，143 项）**：组织人事 + 排班 + 考勤 + 假期 + 薪酬 + 灵活用工 + 外包 + MCP 基础 + 平台底座

**一期验收硬标准**：跑完一个完整月度周期（排班 → 打卡 → 异常 → 确认 → 封账 → 算薪 → 工资条 → 成本分摊），且跨店支援的成本归集与实发账可勾稽。

**二期（P1，78 项）**：招聘 + 绩效 + 学习考试 + 报表增强 + 集成

**三期（P2，19 项）**：智能优化、自定义报表、外部平台对接
