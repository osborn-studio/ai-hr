# 排班、请假与假期给薪统一来源

新请假申请读取当前已发布排班，扣除不计薪休息并排除加班。多班、夜班和跨月都保留原排班工作日的完整净分钟分母；工资归属按实际日历日切片。明确休息或未排班的日期不会回退到旧班表重新扣假。来源存在竞争版本时须先核定。

申请保存来源快照、实际关系、规则和日历版本。真实班段或日分母发生变化后，待批及已批准未休申请不能继续批准或确认已休；可驳回、取消并重新申请，额度按原记录释放。无关员工改班、净时间相同的版本更替不使申请失效。已休假期及已确认工资保留原依据；新的给薪核定使用冻结分母。

周期假期同样读取当前净工作时段。取消后更版重提沿用同一发生根和额度批次，新增必要的正向差额，不改旧发放事实或以新根重复领取。独立核准、资格期限、每日上限和实际已休仍分别校验；排班不作为实际加班证据。

迁移237只新增来源函数、旧申请保护标记及守卫；SQL001–236保持不变，旧申请和工资不回填。新申请、审批、实际确认、给薪核定与工资采用均有来源校验。发布排班和申请使用同一人员锁，避免并发采用过期班段。

隔离实测包括：净请假210分钟、原班390分钟、精确7/13日及140元给薪；跨月夜班两期共用210分钟分母；三次1/3天的额度按日舍入而给薪保留精确分数；法定日历排除；同一日来自两个原班的分母；改班阻断、驳回取消释放、周期重提和真实事务竞争。核心双库各33项、并发4项、周期双库各17项、审批流6项PG及6项PGlite通过；原给薪双库各42项和旧假期回归通过。最终组合回归与工厂结果单独记录。

行业供款演示另补十一月已核与待核依据。收入从已生效小时工资条款及实际4/8小时派生，使用非日薪方式并分别保留原工资期；未建立参保登记、采用工资或移动资金。

本阶段完成统一排班核量。实际假期进入新考勤报告的来源核验及最终资料验收继续，不将本阶段发布视为全项目完成。
