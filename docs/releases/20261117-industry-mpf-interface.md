# 香港行业供款依据与合同现金来源设置

薪酬管理增加“香港行业供款依据”二级入口；工资项目的来源待遇增加“合同条款给薪”。已核合同金额仍须在当期给薪核定中明确选择、独立复核并由工资批次采用，不因签约自动改变已确认工资。

香港薪税政策可明确选择普通月度强积金或行业临时雇员制度。行业政策展示不可任意改写的官方参数快照、适用日期和来源链接；不以餐饮品牌或兼职岗位名称自动判定行业资格。工作日依据分别保存原工资期、每日相关入息、雇员与雇主资格及原件定位，独立核准后由人员参保资格按供款归属月明确引用。非日薪方式保留各原工资期边界，不能把多个工资期合并为月平均。

新增查询 `payroll.native.industry.workspace`、`payroll.native.industry.standards` 及命令 `payroll.native.industry.basis.create`、`payroll.native.industry.basis.approve`。查询在实际雇佣和部门范围内投影，再执行搜索和计数；创建须有关系资料读取和来源写入权限，核准还须完整读取工作日来源并具有独立核准权限。字段授权不能跨授权条目拼合，同一自然人别名和受益本人不能自核。取消雇佣后保留有权查看的原依据，停止继续核准。

本组复用既有 227 计算和数据库约束，没有改写历史 SQL 或另造计算算法。原普通香港制度、合同核定和已确认工资继续保留。

实际 PostgreSQL、原生 REST 和 React 验证覆盖政策、两段原工资期、依据核准、人员资格、批次供款期、试算、独立复核、采用及确认；隔离算例得到雇员供款 50、雇主供款 60、净工资 950 港元。该算例属于独立技术验收，不是标准演示帐套的已发工资，也没有产生银行支付或机构实缴。最终统一验收记录另列本组各项结果。
