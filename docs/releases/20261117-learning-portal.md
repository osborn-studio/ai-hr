# 学习、个人门户与标准薪酬检查点

本组在同一个Node服务中贯通学习结果、人员历史、站内提醒和个人办理。此记录描述代码与隔离验证，未配置的第三方接口及资金指令不视为实连成功。

## 学习与人员全貌

223加入课程、计划、报名、出勤、实操、纪律、题库、组卷、在线考试、阅卷与申诉、成绩发布、岗位资格、结果应用。课程和原件按当前授权返回；部门、人员、成绩及答案分别受限。考试期限任务由同一Node进程的worker入口调度，领域服务只收到当前事务。

人员全貌增加学习记录分区，以同一永久人员及实际任职回读。绩效与薪酬采用候选须独立核准，保留来源版本、父义务及净差，不能因为考试结束直接支付奖金。

## 个人办理与原件

224加入表单原件、引用证据、已读回执和确切命令完成元数据。文件保留真实字节及SHA256，加密保存名称与正文；下载重新校验当前业务、人员、公司及字段授权。浏览器待核记录只存原操作号和带盐指纹；刷新后可核对原提交结果，同内容继续沿用原号。

本人调店先形成意向，经真实人事审批后产生新任职；旧任职和永久人员编号保留。退宿、换房和领用基于本人原业务来源，同一意向只绑定一条审批流程。审批通过仍未交接；实际办理须填写交接凭据，并同时变更原住宿/库存及审批业务状态。已处理来源及实际结果由数据库守卫保护。

## 标准薪酬与完整场景

新增内地和香港标准薪酬方案。香港普通月度MPF用5%及相关最低/最高入息和上限；最低工资核验独立登记适用、工时、非工作给薪及证据后提出核定，不把未知时数当零。地区、有效期、工资和成本币种分开。

完整演示生成工具仅接受明确确认的专用空数据库，拒绝覆盖任何现有表；口令从本地配置读取。生成天意集团、香香鱼米10家内地店、大富烤肉10家香港店、62人和77账号，并形成逐模块私有场景清单。两条待核工资保留，实际NULL工时不伪造为完整工资。
