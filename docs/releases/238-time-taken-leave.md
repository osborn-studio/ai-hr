# 238｜实际休假、考勤与新采用的来源闭环

本版本只追加238迁移。001–237迁移保持原字节，原工资、原卡、已核报表及已有应付保留历史。

## 最终行为

- 新日报按选定净班段与实际已休交集计算；批准占用不当实际已休。多班去重、无薪休息排除，部分休假不补缺失原卡。全班已休可解释免该班缺卡，原卡实际未知仍未知。迟到早退只扣除确证的休假交集。
- 带薪、无薪是时间分类。使用当前已核待遇或明确已发布制度；八成现金不拆成两成无薪时间。跨午夜按实际民用月选择待遇事实，原工作日仍归属原考勤月。原核勤同一时段已计的假期保留或替换，不重复累计。
- Excel及人工月汇总保留原件、原值与来源链。明确选择人工复核时须填原因和依据，再由另一人确认；不反推逐日分钟。确有已休但分类双零的新版本保持未知，原零值仍留在原始记录。
- 新报表确认、工资新预演／采用／确认、服务验收及新对账、原生行业工作日采用，共用本人工作关系当月来源有效性。无关员工、其他雇佣及无关后月变化不阻断本人的旧月。升级前缺少来源证据的报表可读，新的采用须另建复核版本。
- 净在岗时薪与假期零正常工资覆盖可合法组合。时间扣款或时间相关现金项目与正额正常工资覆盖不明时阻断，不能换项目类别重复减发；假期现金仍从原待遇来源成对采用。
- 已确认工资单、已记账供应商应付及其资金义务继续按历史读取，不因来源后续变化撤销。后续差异通过新版本、工资或应付净差处理。

## 页面与授权

日报、月报行详情新增短页签“请假来源”。原请假单每次点击重新核对当前权限；PC和393宽手机共用真实接口。本人的查询硬绑定本人、只开放已核本人报告；公司、部门和本次实际返回字段须由同一完整授权满足，不能借审批授权或拼接字段扩大读取。工作日期及核勤行标识在权限设置字段目录中可选。

来源接口只返回已授权的编号、状态、起止、数量、单位及核勤来源说明，不返回医疗原件、假期待遇金额或银行资料。人工复核值、原始未知值、来源需重核分别展示，失败不显示旧缓存。
