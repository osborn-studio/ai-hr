# 合同给薪桥接（235）

已生效合同条款可经显式映射和独立复核进入原生工资核算。基薪参数替代工资档案的同一公式输入，不新增第二笔现金；一次性和按期义务分别采用，按累计目标与原已确认金额取净差。原合同、原件和已确认工资保留。

入口为“薪酬管理 → 合同给薪核定”；合同条款行可直接预填进入，工资来源区也有对应入口。PC使用分页表格，手机使用卡片。工资采用月与实际银行支付日、税款和供款期间分别处理。

关键校验覆盖真实工作关系、法律主体、有效版本、期间、币种、单位、公式输入依赖、折算和平均工资分类。未知映射和缺段待核，不默认零或1；已核生效的工资影响不能靠漏选绕过。草稿由另一自然人且非受益人复核。

验证：40项领域校验在PGlite与PostgreSQL通过；4项前端来源模型通过；真实PostgreSQL、正式API注册表及Chrome PC/393手机11项操作验证通过。实际预演和确认得到基本工资15000、独立餐费300、合计15300，原工资10000的历史记录保持不变；0外部调用、0银行支付。演示初始化独立克隆核验9项通过，3个核定场景可精确重放，62人77账号20门店及原合同、原件、原配置和工资不变。

操作路线和更正说明见[合同给薪操作](../manual/合同给薪操作.md)。集成迁移为235，沿234现有假期待遇扩展继续分派，不降级已有工资守卫。
