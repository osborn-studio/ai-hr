# V11 易用性与演示场景增补

## 组织图与菜单

人事组织架构的组织导航和人员详情之间新增拖动分隔条，默认组织图区占52%，可调30%至70%。本机记住宽度；方向键每次调2%，Home/End到边界，双击恢复。1100px以下上下排列。树状和网状均可用，部门/岗位/编制及人员权限不变。

菜单顺序：我的工作台、我的办理、人事管理、薪酬管理，再到其他业务模块。人事管理为第一个业务模块；菜单仍按当前权限过滤。

蓝白金主题加强蓝色导航、标题层次、卡片/按钮阴影、金色指标线与节点高亮。PC与手机共享主题，业务表格保持白底。

## 独立增补数据

在既有62人、77账号、20家门店基础上追加，不改原人员、账号、凭据和工资。全部数据为独立编写场景。

- 绩效：4个专项计划（食品卫生、门店运营与班组管理、岗位适应与技能成长、跨店支援协作），48参评目标及评分任务、44评分、40成绩、32已发布。覆盖待评分、评分待复核、成绩待核准、待发布及已发布。未生成额外奖金、工资采用或付款。
- 培训考试：6课程、6计划、24题、6试卷、6考试、72员工任务、54培训考勤、54考试尝试、36成绩。包含未开始、答案已保存、待复核、已发布通过和未通过。课程内容、题目和员工记录可从培训考试及个人门户穿透查看。

两个增补工具均明确要求既有TY-TEST演示帐套及原模块seed已完成，不为生产缺配置自动生成资料。重复执行保留后续人工处理结果。

## 复制到新演示环境

先按部署文档创建完整演示库，再在该库显式执行（数据库连接由环境变量提供，不写入口令）：

```sh
node tools/seed-performance-showcase-demo.mjs --confirm-synthetic --scene-index /private/path/performance-showcase.json
node tools/seed-learning-rich-demo.mjs --confirm-synthetic --scene-index /private/path/learning-rich.json
```

现有演示环境应用前备份，在副本预演后执行。生产数据库禁止执行演示工具。
