# 普通假期给薪接入原生薪酬

普通假期的待遇核定现已接入原生工资。已休假单、真实雇佣、法律雇主、工资所属期、币种、政策版本、工资项目、正常工资覆盖额和证据形成同一来源；独立核定后，仍须经过工资预演、复核、净差采用与确认。旧版仅保存文字批次引用的候选/采用入口已从正式接口撤下，历史记录只作为原复核记录展示，不代表工资入账。

页面在假期台账内分为“给薪核定与工资结果”“实际已休来源”“给薪政策设置”，提供分页、查询、修订、独立核定、实际工资项目及受控附件下载。来源中的新增给薪和正常工资应发差减必须成对核对；已含在月薪中的部分不重复发放。新修订沿同一经济事项结算净差，已确认旧工资保持原记录。

内地病假采用有据核定的地区、医疗期、工资比例和最低日待遇；带薪年假保留正常工资；产假工资与已核生育待遇归属分别核对。分钟假使用该员工当日真实发布班段与实际请假交集，不统一按八小时折算。未知事实不会被转换成零工资。育儿假草稿明确列出地区、子女出生日期/年龄、年度天数、双亲条件、已休余额及给薪口径等待核依据。

香港年假、病假、产假及侍产假分别核定。支持已确认原生工资ADW，也支持明确标记为人工核定的完整工资/日数配对窗口；后一种不会自称已验证原生历史工资。香港连续合约现行17/68规则及其生效时间、病假条件、产假后四周上限、侍产假资格/证明期限均按劳工处公开资料核对。依据：[连续合约](https://www.labour.gov.hk/eng/faq/cap57b_whole.htm)、[病假](https://www.labour.gov.hk/eng/faq/cap57g_whole.htm)、[产假](https://www.labour.gov.hk/eng/faq/cap57h_whole.htm)、[侍产假](https://www.labour.gov.hk/eng/faq/cap57n_whole.htm)、[年假](https://www.labour.gov.hk/eng/faq/cap57i_whole.htm)。规则适用事实仍需有权HR核定。

演示工厂在首次算薪前核定现有内地已休年假的正常月薪覆盖，新增工资差额为零。末阶段另生成香港四日病假的医疗资料、逐月ADW核对表、普通请假/独立审批/实际已休、新核勤月报、给薪核定、最低工资复核及新的工资更正批次。所有人物、医学及历史核对资料均为本地编写的演示资料，未连接医疗或外部签署平台。

香港算例：ADW800港元，四日疾病津贴2,560港元；原正常工资已覆盖2,806.44港元，因此新工资批次只记应发差减246.44港元，员工与雇主MPF各记累计差额−12.32港元。原工资及原始打卡保留，更正工资单不代表已追回或发生银行扣款。已知10月ADW片段与原已确认工资分配一致，其他月份通过明确人工核定的历史核对表支持。产假、侍产假及育儿假没有足够个人凭据的场景保持政策草稿并展示具体缺件。
