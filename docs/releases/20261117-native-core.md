全部为天意集团、香香鱼米与大富烤肉的独立虚构案例。62名永久人员、77账号、20门店；当前45名门店及17名集团/品牌人员，18项职能办理包含1名驻店HR。10月按60名门店和2名总部人员的实际历史关系生成工资及排班。员工与职能账号显式绑定同一人，原工号、旧姓名别名和跨店履历保留。
