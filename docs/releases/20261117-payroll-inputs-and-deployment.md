# 给薪来源与部署入口

请假给薪和合同待遇经独立核定后，可以进入实际工资预演、采用与确认。核准来源、形成工资、发布工资单与实际资金支付分别留存状态，既有确认工资保留原版。

- [假期给薪](20261117-leave-payroll.md)：明确假单、实际已休、工资覆盖、资格和平均工资依据，配对核定本应付与原工资扣减。香港病假演示实际形成更正工资及对应MPF累计净差，不把负差额宣称为已经追回。
- [合同给薪](20261117-contract-payroll.md)：参数替换原公式输入；一次性和按期待遇沿实际经济义务采用，生效期间和工资采用月分别核对。已适用待遇不能通过漏选静默消失。
- [审批消息](20261117-workflow-notifications.md)：原生待办、抄送和结果经独立授权规则进入消息队列；原单、站内阅读、平台回执及业务完成保持独立。

## 成本表与导出

老板成本表汇总已确认工资成本和当前已确认供应商对账成本，按币种核对，授权用户可查看来源原单。旧对账的完整版本不重复相加，代发资金不作为供应商服务成本；尚待核定或金额不可见的来源不按零计入。

Excel或CSV成本导出重新按导出动作、公司范围及字段授权取数，包含全部匹配记录。读取权限不替代导出权限，两个分开的金额与币种授权不能拼接出完整供应商金额。独立浏览器验证实际下载并读回工作簿，同时核对PC、手机与受保护原单穿透。

## 首次建帐

标准初始化不隐式生成演示集团、员工或工资。空库登录后显示建立集团帐表单，完成集团、根帐套和集团公司后自动刷新工作范围，可立即创建品牌公司。原先未绑定身份的初始化管理员在同一事务中成为系统配置人员，不获得普通人事或工资业务身份。

公司或品牌建立成功后刷新全局范围选择，无须重新登录。标准云端关闭历史独立页面和旧业务URL，保留当前版本接口及个人会话操作；旧工资书签转到当前核算首页，不传递旧记录号。

[部署与初始化](../deployment.md)分别说明空业务库、完整演示库、存量升级和云端适配。旧初始只读架构审查保留在本地及Git历史，当前架构说明与实际入口保持一致。

## 验证范围

假期给薪42项、合同给薪40项领域验证分别在PGlite及独立PostgreSQL通过；实际PC/手机分别10项与11项通过。审批消息47项双数据库及16项PC/手机通过。供应商与成本129项双数据库通过，实际成本Excel下载及PC/手机9项通过。

首次初始化7项真实PostgreSQL通过，首次建集团和品牌11项实际PC/手机通过，包括配置人员不能借初始化角色创建业务员工。标准入口26项双数据库通过；既有人事整组回归通过。

独立演示验证覆盖香港四日病假更正、合同参数核定及精确重放，保留62名人员、77个账号和20家门店。新增演示案例不使用客户个人或工资原件，不产生外部签署、消息或银行付款事实。本检查点冻结源的全量npm test、生产构建、文档对象严格核对和全空PostgreSQL完整演示工厂均已通过；实际生成42个新增关联场景。完整交付资料及后续到期提醒的联合验收继续，不把独立断言数当完工比例。
