## 二、多公司与多帐套

| | 帐套（多库） | 法人（同库多行） |
|---|---|---|
| 落地 | 一帐套一独立 PG 库 | `employment.legal_entity_id = 2,3…` |
| 建在哪 | 控制库 `sys_ledger(code,name,db_name,db_host,is_default)`（`064:61-74`、`069:26-28`） | **主档表 `public.legal_entity`**（名称/统一社会信用代码/注册地址/法定代表人/盖章全称/开户行/账号，`160:56-69`）；未登记的主体仍可存在，渲染时显示"法人 #N"（`160:52-55` 写明这是"乐观并存 + 缺失可见"，不加外键） |
| 隔离与汇总 | 物理隔离（连接串不同，跨库不可能查错）；**两帐套不可汇总** | 逻辑隔离（靠 `WHERE legal_entity_id=?` / `requireOrg`）；同库可汇总，**仍无现成实现** |
| 上限 | 一帐套一个根组织（`068:34-37`） | 整数无限，界面只认 1 |

**多帐套 ≠ 多法人。** `068:11-18` 自述两段式：档案级多帐套已有（`sys_ledger` 多行、组织/账号带 `ledger_id`），业务级**没有**（业务表无 `ledger_id`），登记为债 `SUITE.MT`/`SUITE.MT2`（`068:160-165`、`069:64-69`）。
