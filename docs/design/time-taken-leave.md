# 实际休假与考勤核定的来源衔接

本增量在排班核量之后，将实际已休记录接入新考勤版本。审批通过只代表批准占用；只有已确认实际休假的记录才参与核勤。原排班、原卡、已确认考勤和工资保留历史。

## 自动核定

新日报使用所选排班或原考勤班段的净区间，与实际已休区间取交集，扣除无薪休息及已核日历排除。多班合并去重，不把班间空档当休假。同一时段原考勤已计入的假期由明确来源保留或替换，不再累计一次。

实际打卡分钟保持原含义；在岗分钟扣除确证的休假交集。部分休假不能补齐缺失原卡，剩余在岗仍未知时保持未知。整班确证已休可以解释该班无需打卡，在岗为零，但原卡实际仍未知。迟到和早退只扣除其与已休净区间的确证交集。

带薪、无薪描述时间分类。优先使用实际民用日所在月份的当前已核假期待遇事实，也可采用明确已发布的时间待遇制度。八成现金待遇仍是一段带薪假期，不能把两成变成无薪分钟。缺少可靠分类时保持未知，不按假种名称推断。

## 人工报表与原始材料

Excel导入保留文件原件索引、原始值与人工核定值。复制来源已经变化的已核报告时，经办人需明确选择保留原值重新复核，填写原因和依据，再由另一有权自然人确认。新版本保留原报告关联、原始值及原有来源。

人工月汇总不反推逐日工时或每笔假单分钟。确有实际已休但分类双零的，新分类保持未知，原始零值仍留在原始记录；已明确核定的分类分钟保留。每笔相关实际已休均有来源关联，不能只登记一个来源头即宣称自动核定完成。

## 当前来源与工资

来源快照冻结本人工作关系、该报告月份有效区间、完整相关已休集合、实际相关民用月份的待遇版本，以及所选净班段。新增实际已休、相关待遇修订或班段更正会要求另建核勤版本；无关员工、其他工作关系、无关后月待遇或该月以后的离职不应污染本人的历史月。

报告确认核对全部采用范围。工资预演、采用及确认只核对被采用工作关系的当月来源，保留原有报表事实头CAS、独立复核和原卡守卫。升级前缺少新来源证据的报告继续可读，不能直接作为新的当前工资来源。

假期现金给薪及正常工资覆盖差减仍由独立的假期待遇来源成对采用。考勤增量不新建现金项目。重复时间减项、或时间相关现金公式与已核正常工资覆盖无法说明一致时，必须重新拆分基础计薪与假期待遇并独立核定，不能通过改项目类别绕过。净在岗时薪、且假期正常工资覆盖为零的合法组合继续支持。

已确认工资单、工资应付和后续资金取数依据已确认工资义务保留，不因考勤后续变更撤销；更正通过新工资净差处理。

## 页面与权限

考勤行详情提供短页签“核勤值／请假来源”。每次进入来源及读取原请假单都重新检查当前授权。本人入口硬绑定当前人员，仅开放已确认的本人报告；公司、部门及字段权限由同一完整授权满足。工作日期、核勤行标识可在权限设置中选择。

来源展示不包含假期待遇金额、医疗原件或银行资料。人工汇总、分段分类、来源变化和原单受限分别说明；失败不回退显示旧缓存。PC和手机使用同一实际业务接口。

演示刷新工具只接受明确标记的天意62人77账号20门店帐套，保留旧报告和工资，不造人、不改口令、不改原卡，不调用外部服务。返回旧报告到新报告及当前事实头的映射；再次运行已为当前的集合不产生新业务记录。

## 其他当前来源消费者

服务量总源和新验收／新对账使用同一工作关系当月有效性函数，数据库在验收核准及对账核对、共享、同意、记账阶段兜底。原生行业工作日依据在新核准与新采用时重核；明确的外部核定工作日继续原验证，不冒充原生。绩效指标当前没有自动直接采集216报表的入口，本增量不新增采集器。已记账应付和已确认工资的历史读取不触发新采用守卫。

独立字段回归发现通用假期账户投影缺少部门上下文，故本来源接口直接使用当前原生授权模型的同一完整授权和精确六字段白名单，不借其他审批角色兜底，也不扩大到全局账户投影。
