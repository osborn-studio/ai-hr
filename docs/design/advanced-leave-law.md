# 内地香港假期规则官方参考

核查日期：2026-11-17。用途：V17高级假期产品设计和后续独立算法核对。本文是规则研究与开发守卫，未运行应用、未接触数据库或真实员工资料，不构成任何客户个案的法律结论。全部算例均为独立虚构。正式客户适用地区、真实雇主、合同和证明仍须由有权业务人员核定；金额争议或复杂资格交适格专业人员复核，不用“待核”无限阻止其他无争议工资。

## 1 核查范围与结论

已读本地V7第13章、附录B的24项假期范围，V8第12章及工资来源、更正与法定假薪边界，V16第4/8/9/14/20–23/27–28章及来源采用契约。V7的发放、有效期、上下取整、到期清零、转加班等是历史产品能力范围，不是地区法定算法；V17必须把它们放在受法律守卫约束的规则版本中。

必须独立保存四个结果：休假资格、额度取得与消耗、实际休假事实、给薪结果。审批通过不同时证明四者成立；有权休假不一定有法定给薪资格，有疾病证明也不一定同时满足香港疾病津贴条件。法定、合同额外及企业福利额度分别标记，额外福利不得覆盖或缩减法定部分。

## 2 内地基线：年休假优先

### 2.1 资格、年度和额度

《职工带薪年休假条例》自2008-01-01施行；连续工作满一年是资格条件，累计工作年限决定5/10/15日档位（1至不足10年、10至不足20年、20年以上）。法定休假日和休息日不计入年休假。条例另列带薪事假、病假累计等不享受当年年休假的情形，不能仅用本公司入职日推算。[CN01]

实施办法自2008-09-18施行：累计工作含不同用人单位的合资格工作期间；年度为公历年度。新进单位且已具备资格时，以本单位当年剩余日历天数÷365×全年档位额度折算，不足整天部分不享受。终止时按本单位当年已过日历天数÷365×全年应享天数，减当年已安排天数，再核应休未休；不足整天部分不支付，已多安排的法定年假不再扣回。未休报酬300%已含正常工资；基数为给付前12个月剔除加班工资的月平均工资÷21.75，不满12个月按实际月份。[CN02]

设计动作：

| 对象 | 可开发规则与守卫 |
|---|---|
| 资格履历 | 保存连续工作资格起日、累计工作分段、证据及核定人；集团司龄、现主体年资与社会累计工作年限分列。试用期、品牌换店不自动重置法定资格。 |
| 法定年度批次 | 绑定真实用人单位、年度、法定档位、日历天数和公式版本；法律公式分母365作为明确版本参数，不因闰年自动换366。企业给予更优折算另存福利增额。 |
| 取整 | 先保留有理数/Decimal精度和原始天数，再按该法律场景的整天规则处理；不能全局设置所有假种统一四舍五入。半天、小时使用须与法定日额度换算政策、最小单位及员工权益核定分开。 |
| 不享受条件 | 建带薪事假、病假累计及已休年假事实。已享当年后出现特定条件影响下一年时，走下一年度资格核定；不直接制造本年负额度或扣薪。 |
| 跨年 | 原年度、依法跨一年安排的理由/同意与截止安排分别保存；到期进入催办/未休报酬核定，不能法定额度静默清零。职工个人原因书面不休与雇主未安排是不同事实。 |
| 离职结清 | 折算目标、当年已安排、历史未结及已付报酬按父义务核对；已多休不自动追回。正常工资已包含部分与额外应补金额分开，禁止“正常工资+完整300%”重复。 |

### 2.2 假日、工时与调休

2025-01-01起全体公民法定节日为13日；官方工作时间折算通知明确月制度工作日20.67，月计薪天数仍21.75，二者不能混用。[CN03][CN04] 2026放假调休通知是年度日历来源，连休日期不全是法定节日本日。[CN05]

内地标准工时适用场景下，延时、休息日、法定休假日分别受《劳动法》第44条约束，补休不能成为所有加班类型通用替代方式。[CN06] 产品应保存法定日、政府调休工作/休息日、门店排休、实际加班认定四种事实。补休兑换读取适用工时制度、审批事实及加班类型；不因企业配置“1比1调休”就把法定节日加班费归零，也不把香港另定假日当内地调休余额。

### 2.3 病假、医疗期与其他假种模板

内地没有可直接覆盖所有地区的“病假统一扣20%”规则。上海人社现行公开问答以本企业连续工龄、连续病休是否超过6个月分疾病休假工资/疾病救济费档位，并有当地最低工资80%及个人社保公积金排除口径。[CN07] 这仅是上海规则实例；香香鱼米各门店城市尚未核定，不能默认全部适用上海。

医疗期是合同保护期，另建台账，不是可消费有薪病假余额。上海2026官方答复及2025解释仍分别涉及企业年资、最长24个月、连续或累计病休及当地20.67工作日月口径；适用其他地区不得套用上海算法。[CN08][CN09] 到期只生成核验任务，不自动解除劳动关系、停保或删除账号。

国家女职工特别保护基线包括98日生育产假及适用增加、孕检劳动时间、哺乳时间；生育保险给付与雇主承担应分别记录。[CN10] 婚丧、地方生育奖励、陪产、育儿、护理、探亲、工伤停工留薪等先提供可配置模板：地区/对象/证明、日历口径、是否顺延、待遇/保险来源、取得与使用窗口、重复事件控制。地方附加天数和生育津贴补足不得未经核定填全国默认。未发布规则时可保存申请草稿并转HR核定；不得伪造“零日法定额度”。

## 3 香港基线：资格与日历分开

### 3.1 连续性合约与不同权利

自2026-01-18，同一雇主连续受雇至少4周，并满足每周至少17小时，或某周不足17小时但该周连同前三周合计至少68小时的条件。新雇佣首3周不能使用468补足；此前保留旧418版本。依法休假或双方同意缺勤的认定工时亦须考虑，不能只拿打卡小时判断。[HK01]

设计：按真实法律雇主、周起止和时间版本存逐周资格；同雇主多店事实归并且原工时去重，不同法律雇主不能因永久工号相同拼时数。连续性合约、MPF、法定假期给薪及企业承认年资分别判定。缺周数据为“待核”，不能默认为0小时或把临时/兼职标签直接当不适用。

### 3.2 休息日及法定假日

连续性合约员工每7日须至少有一个连续24小时休息日，是否有薪由适用合同约定；替换、紧急工作和自愿工作条件分别管理。[HK02] 2026有15个法定假日，包括新加入的复活节星期一；冬至/圣诞为雇主依法选择的一个假日，不能默认两个都计法定额度。[HK03] 所有适用雇员均有法定假日，假薪一般另须紧接假日前连续性合约满3个月。法定假日工作须处理48小时预先通知、前后60日内另定假日，双方同意代替假日另有30日窗口；不得用现金买断休假权。[HK04]

设计：休息日、法定假日、另定假日、代替假日分别建对象，链接原义务与履行日；碰撞时不得用一次普通调休扣减冒充多项履行。法定假日落休息日的补给保留规则依据。欠休、通知超期进入待办，不因支付额外工资自动完成休假义务。

## 4 香港年假、疾病津贴及ADW

### 4.1 香港年假

连续性合约每完成12个月取得法定年假，年资第1/2年7日，第3年8日，逐年增至第9年及以后14日。一般在随后12个月内安排，通常至少14日前书面通知；分拆和在职以款代假有法定条件，不能全部买断，员工可选择换款的部分限超过10日的部分。[HK05]

周年假期年、共同假期年必须分支：共同假期年安排须提前1个月通知，首不足12个月的按比例额度，日的余数向上计整日；这不是所有香港比例计算通用取整规则。香港连续年假遇休息日或法定假日，指引是年假计入该期间而另补相应休息日/假日，与内地直接排除的计算模型不同。离职须区分已完成假期年未休余额、当前年满3至不足12个月的比例给付及严重不当行为即时解雇情形；前一已完成年度的未休权益不能一并抹掉。[HK06]

开发动作：法定批次记录服务年度、取得日、安排截止、共同年度通知/首期比例与取整理由；在职预借仅作合同福利/预支层，不伪装已经法定归属。年假日历引擎输出“年假消费+替代休息/假日义务”，并给申请人逐日解释。离职比例结果不沿用内地FLOOR或共同假期年CEILING；具体给付精度由对应法定场景和核定规则决定。年假结转或逾期保持原年度血缘，不静默清除法定债务。

### 4.2 香港疾病日与津贴

通常须连续性合约、至少4个连续疾病日、足额累积有薪疾病日及适当证明；孕检、产后治疗、流产等存在适用例外。首12个完整受雇月每月累积2日，此后4日，任一时点最高120日；首类上限36日、第二类84日，使用次序与第二类按要求补充证明不能丢掉。疾病津贴为ADW的4/5。[HK07]

有假薪资格的法定假日与疾病津贴、适用工伤补偿之间需按法定排除规则处理，不双重自动给付；保存各类别累计/使用/给付及返工后7日内签核记录。[HK08] 设计中保留完整疾病事件与证明覆盖区间；是否满足4日不按“申请分成几张单”计算。额度不足部分不倒扣不存在的余额，也不因“不够津贴资格”将经认可的病假自动改成旷工。企业额外全薪病假另设福利层，并明确与法定4/5待遇的包含/补差关系。

### 4.3 ADW与工资采用

ADW按指定日期前12个历月，未满用实际较短期间；各待遇的指定日期、连续多日首日及终止日分别取规则。未获工资或未获全薪的法定排除期间，其日数和对应工资须成对剔除，不能月薪÷30替代。[HK09] 假薪不能当最低工资测试的工作工资填平实际工作小时不足，相关工资标签独立。[HK10]

建议纯函数输出：

`benefit_amount = (window_wages - excluded_wages) / (window_calendar_days - excluded_days) × eligible_benefit_days × rate`

同时返回窗口起止、指定日期、工资行来源、每个排除日原因及金额、分子分母、比例、精度、规则版本。分母≤0或缺少工资来源时进入人工核定，不返回0或无穷；有授权外部基线可采用，但标“外部核定”且保留证据。全薪假期不是仅因“假期”二字就排除；不完整给薪才依排除规则处理。

法定假薪、正常工资覆盖和扣补拆成可解释目标：若当月工资已含相关期间的普通工资，只采用合法替换/补差，不叠加完整假薪。法定规则给薪不等于个人薪俸税月扣；MPF相关入息标签读取V8独立供款规则，不能因为假薪就全计或全免。

### 4.4 其他香港假种模板

产假与侍产假分“可休资格”和“给薪资格”：现行产假14周，法定给薪通常涉及开始前40周连续性合约、通知及证明，4/5 ADW，11至14周给薪合计上限HKD80,000；雇主偿付申请不抵消先向员工依法给薪义务。[HK11] 侍产假现行5日，可分次，休假窗口为预产期前4周至实际出生后14周；给薪40周资格按实际休假日核，证明提交期限和给薪时点另存。[HK12] 其他婚丧、福利、育儿或护理模板不冠“香港通用法定天数”，由适用合同和规则核定；通知/证明例外不得硬编码为一律拒绝。

## 5 配置、人工调整与跨域守卫

### 5.1 规则版本最低字段

`jurisdiction + locality + actual_employer_scope + effective_from/to + leave_kind + statutory_or_extra + eligibility_version + calendar_version + accrual/grant_formula + usage_unit + rounding_stage/mode + evidence_policy + pay_rule_ref + expiry_action + source_url + approved_by/at`。

按事件发生及取得期间选择版本；“今天最新规则”不重算并覆盖历史。适用地区不明、政策待核、明确不适用和实际为0分开。参数可改，但法定模板下调、全假种清零、跨主体拼资格、无依据扣薪等受保护操作必须被阻断/转专业核定，而非仅出黄色提示。

### 5.2 人工调整不是直接改余额

1. 发放、预占、使用、释放、冲销、延期、结转、合法结清均为批次账本事件。余额由账本推导，人工调额必须带对象、原版本、理由、证据、审批及差额。
2. “覆盖导入”需对预演时基线版本做CAS重验；并发新增使用或预占后原批准失效。已使用/预占不能被覆盖文件删除；发现不足走差异待核，不制造负可用数掩盖历史。
3. 已批准假期取消采用冲销/销假，保留原计划、真实休假、考勤与工资采用血缘。重复回调仅一次生效；实际已休不能只改申请为撤回就抹去。
4. 法定日历、资格或工资窗口被更正，应列影响人员/日期/批次/工资版本，重新核定目标净差；已发工资走受控补退，不直接从下一月工资任扣。
5. 同一法律雇主内换店不重复取得一份年假；不同法律主体转移保存旧雇主未结义务、新主体资格及合同认可额度。所谓“余额承接”必须有原批次血缘、双方依据与一次性交接记录，不能把清零、折现、承接同时执行。
6. 外包/派遣人员按实际雇主及服务关系办理，客户门店可认定工作/缺勤事实，不能因打卡关联就建立本公司有薪假义务。供应商确认不证明个人法定假薪已经支付。
7. 流程设计器管批准，假期域负责资格与账本生效，考勤域核定缺勤/工时，薪酬域采用给薪结果，银行域认定付款；本人、店长、品牌HR、集团HR、供应商的查询/导出/附件权限分别约束。医疗附件不随集团全貌汇总广泛暴露。
